# هشت سینما | بهمن سبز

نسخه فارسی و راست‌چین پنل برنامه ۴۰روزه. سایت در ریشهٔ مخزن قرار دارد و بدون نصب وابستگی اجرا می‌شود.

```sh
python3 -m http.server 8080
```

- فایل‌های ورد اصلی در `docs` و متن استخراج‌شده در `data.js` قرار دارد. برنامه شامل ۲۴ اجرای محلی اقدامات عمومی و ۳۲ اقدام اختصاصی مستند است. موعد، مسئول و گزارش اجرای فاقد داده پس از ثبت واقعی نمایش داده می‌شود.
- پیکربندی عمومی Supabase در `config.js` شامل نشانی پروژه و کلید publishable است. کلیدهای دارای دسترسی مدیریتی را اینجا وارد نکنید.
- برای راه‌اندازی روی پروژه دیگر، مهاجرت SQL پوشه `supabase/migrations` را اعمال کنید، نشانی و کلید publishable را به‌روز کنید.
- بازدیدکنندگان بدون حساب کاربری می‌توانند کارت‌ها را ویرایش و جابه‌جا کنند. تغییرات مشترک در Supabase ثبت می‌شوند. دسترسی عمومی فقط برای خواندن، درج و به‌روزرسانی کارت‌هاست.

- در صفحهٔ هر سینما، زبانهٔ «CRM و سوابق تماس» از حساب و عضویت موجود پروژه هشت سینما استفاده می‌کند. داده‌های CRM در جدول‌های جداگانه با دسترسی اعضای پروژه ذخیره می‌شوند. شناسه‌های ۰ تا ۷ مطابق ترتیب ثابت سینماها در `app.js` هستند و مقدار ۱- برای تگ‌های مشترک تماس‌گیرندگان است.
