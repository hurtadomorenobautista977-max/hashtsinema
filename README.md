# هشت سینما | بهمن سبز

نسخه فارسی و راست‌چین پنل برنامه ۴۰روزه. سایت در ریشهٔ مخزن قرار دارد و بدون نصب وابستگی اجرا می‌شود.

```sh
python3 -m http.server 8080
```

- فایل‌های ورد اصلی در `docs` و متن استخراج‌شده در `data.js` قرار دارد. برنامه شامل ۲۴ اجرای محلی اقدامات عمومی و ۳۲ اقدام اختصاصی مستند است. موعد، مسئول و گزارش اجرای فاقد داده پس از ثبت واقعی نمایش داده می‌شود.
- پیکربندی عمومی Supabase در `config.js` شامل نشانی پروژه و کلید publishable است. کلیدهای دارای دسترسی مدیریتی را اینجا وارد نکنید.
- برای راه‌اندازی روی پروژه دیگر، مهاجرت SQL پوشه `supabase/migrations` را اعمال کنید، نشانی و کلید publishable را به‌روز کنید و شناسه حساب‌های مجاز Supabase Auth را به `public.eight_cinemas_members` اضافه کنید.
- ویرایش و جابه‌جایی کارت‌ها پس از ورود از دکمه «اتصال به فضای کاری» فعال می‌شود. تغییرات کارت‌ها در Supabase ثبت می‌شوند.
