# هشت سینما | بهمن سبز

نسخه فارسی و راست‌چین پنل برنامه ۴۰روزه. سایت در پوشه `dist` قرار دارد و بدون نصب وابستگی اجرا می‌شود.

```sh
python3 -m http.server 8080 --directory dist
```

- فایل‌های ورد اصلی در `docs` و متن استخراج‌شده در `dist/data.js` قرار دارد. برنامه شامل ۲۴ اجرای محلی اقدامات عمومی و ۳۲ اقدام اختصاصی مستند است. موعد، مسئول و گزارش اجرای فاقد داده پس از ثبت واقعی نمایش داده می‌شود.
- پیکربندی عمومی Supabase در `dist/config.js` شامل نشانی پروژه و کلید publishable است. کلیدهای دارای دسترسی مدیریتی را اینجا وارد نکنید.
- برای راه‌اندازی روی پروژه دیگر، مهاجرت SQL پوشه `supabase/migrations` را اعمال کنید، نشانی و کلید publishable را به‌روز کنید و شناسه حساب‌های مجاز Supabase Auth را به `public.eight_cinemas_members` اضافه کنید.
- پیش از ورود، تغییرات در مرورگر ذخیره می‌شوند. ورود از دکمه «اتصال به فضای کاری» حالت مشترک را فعال می‌کند. تغییرات محلی و مشترک مستقل‌اند.
